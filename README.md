# StreamSource

StreamSource is a bring-your-own-playlist media player for Android phones, Android TV and Meta Quest. You add your own playlist or provider details; StreamSource gives you a fast, clean player with a TV guide, an On Demand library, live sports scores that play, and a "Trending Now" shelf matched against your own library.

- No accounts and no sign-in
- No personal data collected
- Read-only public data only

StreamSource is currently in closed testing on Google Play, with a production launch expected in December 2026.

Privacy policy: https://sites.google.com/view/streamsourceplay/privacy-policy
